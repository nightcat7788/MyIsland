MyIsland · Windows 灵动岛
=========================

【快速开始】
1. 双击「启动 MyIsland.bat」（需 PowerShell 7/pwsh）或直接运行 Island.App.exe
2. 屏幕顶部出现胶囊即启动成功

【日常使用】
- 鼠标悬停岛体 → 展开面板（监控 / 剪贴板·文件 / 设备电量 / 控制 四个页面，顶栏图标切换）
- 鼠标移开 → 自动收起
- 岛体上滚轮 → 切换收起视图（仪表盘 / 时间+天气 / 信息胶囊 / 系统读数 / 设备电量 / 剪贴板 / 小形象）
- 双击岛体 → 长关（不再自动展开），再双击恢复
- 拖文件到岛体 → 文件中转暂存
- 调节系统音量时 → 岛内浮条显示音量
- CPU/GPU ≥88°C → 岛内红色高温浮条提醒（每分钟最多一次）

【收起视图】
- 仪表盘：核心柱 + CPU/GPU/SSD 温度 + 内存% + GPU% + 硬盘% + 电池 + ↑↓ 网速（读数 ≥70% 橙 / ≥90% 红）
- 时间+天气：时间 + 当地天气（Open-Meteo，免配置）+ 网速
- 信息胶囊：时间 + CPU/MEM/GPU 读数表盘 + 网速
- 小形象：10 秒后自动变成信息胶囊，30 秒后变回（滚动滚轮可手动切走）
- 小形象有生命：CPU 高温流汗、磁盘打满晕眩、深夜打瞌睡（Zzz）、鼠标靠近换心情、点击会惊讶

【硬件监控说明】
- CPU/GPU/内存/网速/硬盘活动：Windows 性能计数器（PDH），无需任何驱动、无需管理员
- Top 进程：按 TotalProcessorTime 差分，3 秒一采
- 设备电量（蓝牙/HID/笔记本电池）：WMI，只读
- CPU/GPU/SSD 温度：需要【管理员权限 + PawnIO 驱动】（与 LiteMonitor 同方案）
  · 托盘右键 →「以管理员重启（获取温度读数）」即可
  · Intel 核显温度 Windows 无公开接口，显示 "--" 是如实状态
- 全部读数读不到时显示 "--"，绝不伪造

【系统托盘】
右键托盘图标：
- 展开/收起、面板主题（9 套）、停靠边缘（上/下/左/右）、展开方式（悬停/常驻/长关）
- 收起视图、小形象款式（经典双眼 / 独眼 / 猫咪 / 机器人）
- 工具：打开文件中转目录、清空剪贴板历史
- 以管理员重启（获取温度读数）、退出

【数据位置】
%LOCALAPPDATA%\MyIsland\
  settings.json      配置（原子写入）
  run.log            启动心跳
  crash.log          异常日志
  thermal-diag.log   温度传感器诊断（首次采样时导出）
  FileTray\          文件中转目录
