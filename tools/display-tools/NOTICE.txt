MyIsland · macOS 显示器控制组件说明
===================================

MyIsland 的 macOS 外接与内建显示器控制工具（ddc-helper / screen-guardian / island-screens）
移植并改编自开源项目 LunarCN 0.6.1（参考 Lunar 公开实现，不包含 Lunar Pro 的专有代码）与 m1ddc。

上游项目：
- LunarCN：https://github.com/fengly78/LunarCN（MIT）
- Lunar：https://github.com/alin23/Lunar（MIT）
- m1ddc：https://github.com/waydabber/m1ddc（MIT，基线提交：7339ceebb03f691b1eaeb8471dca301d215d19c8）

本地变更摘要：
- 按协议长度发送完整数据包，保留为零的校验字节。
- 直接解码 16 位数值，修复 sizeof(2) 导致的越界拷贝。
- 校验读取响应的头、长度、结果码和校验和；明确区分显示器返回「不支持该 VCP 码」（退出码 3）与 I2C 总线超时/通信失败（退出码 1）。
- 使用独立的受限控制入口，核对显示器 ID 与 UUID，并在进程终止信号与父进程退出时自动恢复内建屏幕。
