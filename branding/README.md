# MyIsland 品牌规范（Branding）

## 图标构成（2026-11-24 第二版）

| 元素 | 含义 | 取值 |
|---|---|---|
| 圆角方形底板 | macOS 规范的图标底座；深色渐变，浅/深壁纸都清晰 | 圆角 22.5%，`#2E3240 → #15171E` |
| 胶囊岛 | 产品本体"灵动岛"，屏幕顶端那个胶囊 | 宽 71.5%，`#0B0D12` |
| 270° 仪表环 | 监控的核心隐喻（与面板表盘同款），已用量 72% | `#5A96FF`，轨道 `#2A2F3C` |
| 三条读数条 | CPU / 内存 / 网速，长度各不同 | `#5A96FF` / `#4FE3D7` / `#3CBE78` |

> 旧版图标（玻璃辉光 + 4 根频谱柱）已弃用：频谱是音频隐喻，与"系统监控"定位不符；
> 渐变辉光在 16/32px 糊成一团。新图标纯色 + 清晰轮廓，每个尺寸独立渲染，小尺寸专门加粗。

## 色彩

```
主强调   #5A96FF   （界面 Accent / 仪表环 / CPU）
青       #4FE3D7   （内存）
绿       #3CBE78   （网速下行 / 正常）
暖强调   #E8A24A   （温度/警示）
深底     #0B0D12   （胶囊岛）
```

## 资产清单（branding/）

| 文件 | 用途 |
|---|---|
| `tools/IconGen/icongen.swift` | 矢量源文件（CoreGraphics，可改参数重新生成） |
| `island.icns` | macOS 应用图标（16→1024 全尺寸 @1x/@2x） |
| `island.iconset/` | icns 的源目录 |
| `island-logo.ico` | Windows 图标（16/32/48/256） |
| `island-logo-{16..1024}.png` | 各尺寸位图（网页/文档/商店） |
| `menubar/` | 菜单栏胶囊图标（保持原样） |

## 重新生成

```bash
bash tools/IconGen/build.sh
```

## 使用规范

- 最小使用尺寸 16px（此时只保留胶囊 + 仪表环 + 三条色块，无高光）；
- 四周保留 ≥ 10% 透明边距（macOS 规范）；
- 禁止改变读数条顺序（CPU / 内存 / 网速，与面板一致）；
- 单色场景：胶囊轮廓 + 单色仪表环。
