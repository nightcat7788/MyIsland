## 口径说明

- 「该机不支持 / 读不到」是**真实状态**，不算失败（例如台式机没有亮度读数、非管理员读不到某些 WMI 项）。
- 只有**抛异常**才算失败 —— 那说明产品代码在这台机器上跑不通，是真缺陷。
- 锁屏 / 睡眠 / WLAN 开关 / 蓝牙开关**永不自动执行**：它们会打断你手上的事或切断网络。
